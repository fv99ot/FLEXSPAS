<product_requirements>
The user requested a check-in system for FLEX_LA (later Flex Spa Los Angeles) bathhouse.
**Core Features:**
1.  **Login Portal:** Role-based access for Managers (Admin) and Employees (limited control). Managers create employee logins.
2.  **Customer Management:**
    *   Search existing customers by first/last name or ID.
    *   Add new customers (required: first/last name, ID number, DOB, ID exp. date).
    *   Customer profile with a notes section for comments.
    *   Option to 86 (ban) a customer.
3.  **QR Code Membership Form:** Customers can scan a QR code to pre-fill a new membership form.
    *   Required fields: first/last name, ID number, ID expiration date, state of ID, today's date, signature.
    *   Include a paragraph of rules and liability waiver (provided by user).
    *   Added requirement: must have hard copy ID at the beginning, and be ready to show ID reminder at the end.
    *   New customer queue: Customers fill the form online, but are added to a pending customer queue for staff approval (after ID verification) before being added to the main list.
4.  **Check-in Workflow:**
    *   Membership required for entry (0 1-day pass, 5 6-month pass).
    *   Room/Locker assignment: Lockers (5 weekday, 8 weekend), Small Changing Room (no TV, 3 weekday, 6 weekend), Changing Room (with TV, 0 weekday, 5 weekend), Deluxe Changing Room (with TV, 5 weekday, 0 weekend). Prices exclude membership.
    *   Locker/Room ranges: Lockers (40-153), Small Changing Rooms (7-24), Changing Rooms (1-6 & 25-32), Deluxe Changing Rooms (34-39).
    *   Initially, all were listed as rooms; user requested separate dropdowns for Lockers and Rooms with color coordination.
    *   Added feature: Visual room/locker availability map with color coding (Green=Available, Red=Occupied).
    *   Glitch: Check-in process pausing/not finalizing transaction.
5.  **Time Tracking & Business Rules:**
    *   8 hours per session.
    *   Max 3 sessions, then a 24-hour blackout.
6.  **Payment & Transaction Finalization:**
    *   System to track sales (cash/card).
    *   Additional items: dildos, sandals, cleaning fees, lost key fee (added last). Customer must pay OT or lost key fee before re-entry.
    *   Admin should be able to add/remove/enable/disable these additional transaction items.
    *   Discount option to be added at the end of transaction.
    *   Secret code (shift+1+0) for 100% ghost discount, not shown on reports.
7.  **Reports:**
    *   System to track employee discounts.
    *   End-of-shift sales report.
8.  **Branding & UI:**
    *   Initially FLEX_LA, later changed to Flex Spa Los Angeles.
    *   Copy background and font from  (dark black, subtle bubble/water pattern, bold sans-serif, red accents, white text).
    *   Fix input visibility (typed text not showing).
9.  **Advanced Features (Pending/Ongoing):**
    *   Option to upgrade a customer: pay difference +  cleaning fee if changing rooms.
    *   Waitlist integration: for unavailable rooms, staff prompted for upgrades. Options for specific room waitlists.
</product_requirements>
